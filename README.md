# Department of Computing Website

A beginner-friendly multi-page website created for the Version Control, Git and GitHub assignment.

## Pages
- `index.html` — Home page
- `about.html` — About Us page
- `programmes.html` — list of example study areas
- `contact.html` — Contact Us page with a demonstration form
- `styles.css` — shared styling and responsive layout
- `script.js` — mobile navigation, current year, and demo form feedback

## Run locally
Open `index.html` in a web browser. No build tools are required.

## Before submission
1. Replace the sample email and campus details in `contact.html`.
2. Replace the example study areas in `programmes.html` with your institution's official programmes if required.
3. Add your name and institution details to your assignment report.
4. Follow the Git commands in the accompanying `GIT_STEPS.md` file.

The contact form is a front-end demonstration and does not send messages to an email inbox.
